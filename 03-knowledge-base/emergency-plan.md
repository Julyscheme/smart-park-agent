## 一、火灾应急预案

### 1.1 报警与初期处置

**发现火情时——**
1. 立即拨打119报警，同时通知园区消防控制室（24小时值班电话：021-XXXX-XXXX）
2. 启动最近的手动报警按钮
3. 在确保自身安全的前提下，使用灭火器或消火栓进行初期扑救
4. 关闭起火区域的门窗，防止火势蔓延（切勿关闭电源总闸，以保证消防设备运行）

**消防控制室接警后——**
1. 确认火情位置和等级
2. 启动消防广播，通知人员疏散
3. 启动排烟系统和消防泵
4. 降下防火卷帘门
5. 向园区总经理和安全管理部负责人报告

### 1.2 人员疏散

**疏散顺序**：起火楼层 → 起火楼上层 → 起火楼下层 → 相邻楼栋

**疏散路线**：
- A座：经1号、2号楼梯间下行至中心广场集合点
- B座：经3号、4号楼梯间下行至北侧停车场集合点
- C座：经5号楼梯间下行至东侧绿地集合点

**注意事项**：
- 严禁使用电梯
- 用湿毛巾捂住口鼻，弯腰低姿前进
- 到达集合点后，各部门清点人数并向总指挥报告

### 1.3 灭火力量编成

| 编组 | 职责 | 装备 |
|------|------|------|
| 灭火行动组 | 使用消防设施扑救初期火灾 | 灭火器、消火栓、消防水带 |
| 疏散引导组 | 引导人员安全疏散 | 反光背心、荧光棒、喊话器 |
| 通讯联络组 | 保持内外通讯畅通 | 对讲机、应急电话 |
| 医疗救护组 | 现场急救和伤员转运 | 急救箱、担架、AED |
| 后勤保障组 | 保障消防水电和设备运行 | 工具包、应急照明 |

## 二、停电应急预案

### 2.1 分级响应

**一级停电（市电中断，预计恢复 > 2小时）**：
1. 自动切换至发电机供电（切换时间 < 30秒）
2. 发电机油料储备可维持8小时运行
3. 通知供电局确认原因和预计恢复时间
4. 通知各入驻企业停电情况

**二级停电（局部跳闸，影响部分楼层）**：
1. 物业电工10分钟内到场排查
2. 确认故障点，隔离故障区域
3. 15分钟内恢复非故障区域供电

### 2.2 发电机管理

- 发电机功率：800kW（可保障电梯、消防、公共照明、弱电机房）
- 每周六上午试运行15分钟
- 油料储罐容量：1,000L
- 油料供应商：XX能源（紧急配送电话：138-XXXX-XXXX）

### 2.3 恢复供电后的检查清单

- [ ] 电梯复位运行
- [ ] 空调系统重启
- [ ] 门禁系统恢复
- [ ] 监控系统恢复
- [ ] 服务器和网络设备重启
- [ ] 消防系统复位

## 三、水管爆裂应急预案

### 3.1 处置流程

1. **发现漏水后**：立即通知物业工程部（24小时电话：021-XXXX-XXXX）
2. **物业到场**：15分钟内到达现场，定位漏水源头
3. **关闭阀门**：关闭对应区域的供水阀门
4. **排水处理**：使用排水泵或吸水机清除积水
5. **电梯保护**：如漏水靠近电梯井，立即停梯并设置挡水板
6. **损失评估**：拍照留证，评估设备和装修损失

### 3.2 常见爆管位置的阀门位置

| 爆管位置 | 关闭阀门位置 | 影响范围 |
|---------|------------|---------|
| A座1层卫生间 | A座地下一层水井间 | A座1-3层停水 |
| B座管道井 | B座每层水井间 | 单层停水 |
| 室外主管道 | 园区总水表井（东门入口） | 全园区停水 |

## 四、电梯困人应急预案

### 4.1 救援流程

1. 监控中心发现困人信号或接到求助电话后，立即通知电梯维保单位
2. 安保人员3分钟内到达困人楼层，安抚被困人员
3. 电梯维保人员30分钟内到达现场实施救援
4. 严禁非专业人员强行开门救援
5. 救援完成后，记录故障原因并上报

### 4.2 电梯维保单位信息

- 维保单位：XX电梯有限公司
- 24小时救援电话：400-XXXX-XXXX
- 合同编号：DT-2025-038
- 维保频次：每15天一次
